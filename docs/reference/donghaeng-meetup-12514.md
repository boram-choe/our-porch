## 호스트 소개

- 예비·신혼부부 교육 현장에서 매년 수백 쌍의 커플을 만나며, 사랑할 때는 잘 보이지 않다가 함께 살면서 드러나는 현실적인 차이를 관찰해옴.

- **"결혼의 정답을 알려드리기보다, 각자의 이상적인 결혼 생활 기준을 발견할 수 있도록 질문과 사례를 나누고 싶습니다."**

## 모임 소개 (요지)

1. 공감 훅: 결혼하고 싶은 마음은 있는데, 어떤 결혼을 원하는지는 잘 모르겠다.
2. 구체적 궁금증: 사랑과 함께 사는 일은 어떻게 다른지, 돈·가족 이야기는 언제 꺼내야 하는지, 다른 사람은 무엇을 기준으로 결혼을 결정하는지.
3. 문제 정의: 좋아하는 마음이 같아도 돈 쓰는 방식, 가족과의 거리, 집안일 기준, 갈등 푸는 방법은 모두 다를 수 있다.
4. 포지셔닝: 결혼을 해야 한다/하지 말아야 한다는 정답을 찾지 않는다. 각자의 경험과 생각을 나누며 "나는 어떤 사람과 어떤 일상을 만들고 싶은지" 살펴본다.
5. 결과물: 4번의 만남이 끝나면 **'나의 사랑과 결혼 기준 노트'** 완성.

## 회차별 커리큘럼

회차마다 동일한 틀: `참고할 콘텐츠(선택)` → `함께 나눌 이야기 ×3` → `함께 할 활동 ×3` → 한 문단 요약. 별 개수로 깊이(난이도)를 표시.

### 1회차 ⭐ — 나는 왜 결혼하고 싶을까, 혹은 망설이고 있을까?
- 이야기: 결혼하고 싶다는 생각이 드나요? / 결혼이 망설여지는 순간은? / 동경하거나 피하고 싶은 결혼생활의 장면은?
- 활동: 결혼 기대와 망설임 **카드 고르기** / 동경·회피 장면 나누기 / 결혼에 대한 현재 마음을 **한 문장으로 적기**
- 요약: 기대와 두려움을 솔직히 살피고, 보고 경험한 장면이 내 결혼관에 준 영향을 이야기한다.

### 2회차 ⭐⭐ — 사랑에도 번역이 필요할까?
- 참고: 도서 『5가지 사랑의 언어』 (게리 채프먼)
- 이야기: 연애할 땐 괜찮지만 함께 살면 힘들 것 같은 차이는? / 열심히 표현했지만 오해받은 경험은? 사랑받는다고 느끼는 순간은?
- 활동: 5가지 사랑의 언어 **테스트 진단** / 나에게 꽂히는 사랑 표현 **리스트 작성** / 바라는 것을 비난 없이 표현하는 **문장 만들기**
- 요약: 정밀 질문지로 나만의 '사랑의 언어'를 진단하고, 서로에게 맞는 소통 기술을 알게 된다.

### 3회차 ⭐⭐⭐ — 사랑만으로 넘기기 어려운 돈·가족·가사의 문제
- 이야기: 우리 집만의 명절/연락 문화는? 생활비와 개인 소비의 기준은? / 가족에게 어디까지 알리고 얼마나 자주 만나고 싶나? / 가사와 돌봄에서 포기하기 어려운 기준은?
- 활동: 실제 커플 **갈등 사례** 읽고 입장 나누기 / 돈·가족·가사를 **중요함 / 조율 가능 / 포기하기 어려움**으로 분류 / 함께 살 사람에게 묻고 싶은 **현실 질문 작성**
- 요약: 익명화한 실제 교육 사례로 서로의 기준이 얼마나 다를 수 있는지 확인하고, 결혼 전에 나눌 질문을 정리한다.

### 4회차 ⭐⭐⭐⭐ — 우리는 어떤 사랑과 결혼을 원하는 걸까?
- 이야기: 어떤 사람과 있을 때 가장 나답나? / 함께 사는 사람과 만들고 싶은 평범한 하루는? / 지금 나에게 결혼은 어떤 선택인가?
- 활동: 앞선 세 회차 기록을 **한 장으로 정리** / 함께 살 사람에게 꼭 묻고 싶은 **질문 10가지 완성** / 만들고 싶은 사랑과 생활의 한 장면 적고 공유
- 요약: 결론을 내리기보다, 어떤 사람과 어떤 일상을 만들고 싶은지, 관계에서 무엇을 지키고 싶은지 말해본다.

## 참가자 후기

- (3회차 후기) "가정을 꾸리는 것에 대한 정보와 **재정 관련 이야기**를 들을 수 있어서 좋았어요. 같이 스낵과 음료도 마시니까 금상첨화."
- "결혼 준비는 열심히 했지만, 정작 결혼생활을 어떻게 만들어갈지는 잘 몰랐던 것 같아요. 이 모임은 **상대를 바꾸는 방법이 아니라 나 자신을 이해하고, 더 좋은 배우자가 되는 방법**을 생각하게 해줬습니다. **남편과 함께** 서로를 더 깊이 이해할 수 있었고, 지금도 일상 속에서 도움이 되는 이야기들이 많았습니다. 결혼식보다 더 오래 남을 배움."
- 현장 사진: 10명 안팎이 큰 테이블에 둘러앉아 활동지에 직접 적는 워크숍 형태, 화면에 질문 띄움.

## 이 레퍼런스에서 가져갈 포인트

1. **정답 대신 질문** — 전문가가 결론을 주지 않고 참가자가 "자기 기준"을 발견하게 한다.
2. **점진적 깊이** — 내 마음 → 소통 방식 → 현실 갈등(돈·가족·가사) → 종합. 별로 난이도를 시각화.
3. **반복되는 회차 템플릿** — 나눌 질문 3 + 손을 쓰는 활동 3(카드 고르기, 진단, 3단 분류, 한 문장 쓰기).
4. **손에 남는 결과물** — 기준 노트, 질문 10가지. 후기에서 "결혼식보다 오래 남는다"로 돌아옴.
5. **실제 사례의 힘** — 익명화한 현장 사례가 신뢰와 몰입을 만든다.
6. **커플·개인 모두 참여 가능** — 후기에 부부 동반 참여가 가치로 언급됨.
7. **분위기 요소** — 스낵·음료, 소규모 테이블 토론이 만족도에 기여.
